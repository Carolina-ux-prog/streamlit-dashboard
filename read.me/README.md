# Vehicle Data Dashboard

## Descrição
Aplicação web desenvolvida com Streamlit para análise exploratória de dados de veículos usados.

## Objetivo
Explorar dados de veículos através de visualizações interativas.

## Funcionalidades
Histograma de quilometragem
Gráfico de dispersão (preço vs quilometragem)
Interface interativa com Streamlit

## Tecnologias
Python
Pandas
Plotly
Streamlit
